# 도예 공방 예약

기존에 검토한 가상 도예 공방 예약 예제를 바탕으로 만들었다. 사용자는 지역과 수업 종류로 클래스를 찾고, 날짜·시간·인원을 선택해 예약한다. 예약자 정보를 입력한 뒤 결제 직전에 일정, 인원, 금액을 대조할 수 있다.

첫 더미에서 검색 초기화, 결제 재시도, 취소 확인창 닫기는 연결이 끊겨 있다. 해당 화면의 **개선안 보기**에서 내용을 확인하고 **개선안 적용**을 선택한 뒤 같은 조작을 다시 시도한다.

| 확인할 동작 | 더미에서 해볼 일 |
|---|---|
| 검색과 필터 | 영문 예제에서 `woodwork`를 검색해 빈 결과에서 돌아온다. 지역을 Seongsu, 수업을 Wheel로 골라 목록이 좁혀지는지 본다. |
| 입력과 복귀 | 11월 28일 16시, 2명을 고른다. 필수 정보 없이 진행해 보고, 입력을 마친 뒤 결제 확인에서 돌아와 선택값을 대조한다. |
| 결제 재시도 | 결제 확인에서 실패를 재현한다. 재시도 후 예약자, 일정, 인원과 금액을 다시 확인한다. 결제는 더미 안에서 시뮬레이션한다. |
| 취소 | 내 예약에서 취소 확인창을 닫고 예약 상태를 확인한다. 다시 열어 취소를 확정하고 목록의 상태를 대조한다. |

취소 가능 시점과 환불 문구, 결제 시간 초과 시 실제 승인 여부를 확인할 방법은 미정이다. 테스트 모드에서는 취소 동작에 준비된 오류를 넣어 검수 결과와 정상 흐름을 비교할 수 있다.
