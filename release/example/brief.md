# Night Atlas · 야간 전시 설치실

서관 1층 전시의 야간 설치팀이 쓰는 데스크톱 작업대다. 팀은 평면도에서 A실과 B실을 직접 골라 각 작품의 설치 도면과 담당 정보를 확인한다. A실은 천장에 거는 작품이고 B실은 벽면의 조명 작품이다. 작업표에는 반입, 설치, 조명 시험, 교대 시간이 있다.

A실 점검자는 다음 조에 넘길 메모와 확인 체크를 입력한다. 두 항목을 채워야 인계 내용을 검토할 수 있다. 확인 단계에서 작성으로 돌아가 메모를 고칠 수 있고 전송 후에는 인계한 메모를 같은 세션에서 다시 읽을 수 있어야 한다. 재열람을 별도 기록 화면으로 할지는 미정이다. 실제 작업자에게 발송하는 기능은 모의 처리한다.

이 예제의 구역, 시각, 인물, 도면은 가상의 전시를 위해 만들었다. 배포용 더미에는 전송 후 재열람 연결 하나를 의도적으로 비워 둔다.
